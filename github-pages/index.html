Flatpak · Linux

Kontoauszuege App

Persönliche Finanzverwaltung – lokal, ohne Cloud. Basiert auf Spring Boot & Electron.

Schnellinstallation

App direkt per .flatpakref installieren (inkl. GPG-Verifikation):

flatpak install --user https://jngross95.github.io/kontoauszuege-app/kontoauszuege.flatpakref
Mit Discover / GNOME Software öffnen (.flatpakref)

Manuell – App installieren

Fügt den Remote automatisch hinzu (inkl. GPG-Key) und installiert die App:

flatpak install --user https://jngross95.github.io/kontoauszuege-app/kontoauszuege.flatpakref

App starten

flatpak run com.example.kontoauszuege

Updates

flatpak update com.example.kontoauszuege
